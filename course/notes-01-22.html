    Subsection Exact Equations

    We’ll talk about just enough of the Calc III Chain Rule to motivate our next topic. Suppose \(z = F(x, y)\text{.}\) Then there are two partial derivatives \(F_x, F_y\text{.}\) But also, thinking of \(y\) as a function of \(x\text{,}\) there’s a derivative \(\frac{dy}{dx}\text{.}\) If we start with an equation like \(F(x, y) = C\text{,}\) the Calc III Chain Rule gives:
    \begin{gather*} F_x + F_y \frac{dy}{dx} = 0 \quad \Rightarrow \quad M + N \frac{dy}{dx} = 0. \end{gather*}
    🔗
    So, suppose we start with a differential equation of the form:
    \begin{gather*} M(x, y) + N(x, y) \frac{dy}{dx} = 0. \end{gather*}
    Then:
    1. Can we tell whether there is some \(F(x, y)\) such that \(M = F_x, N = F_y\text{?}\) If so, then the differential equation is called exact.
      🔗
      🔗
    2. Can find find such an \(F\text{?}\)
      🔗
      🔗
    3. If so, then the (implicit) solution to the differential equation is \(F(x, y) = C\text{.}\)
      🔗
      🔗
    🔗

    Fact 20.

    For nice enough \(F(x, y)\text{,}\) \(F_{xy} = F_{yx}\text{.}\)
    🔗
    🔗

    Example 21.

    Consider \(F(x, y) = xy + x^2 + \sin(y)\text{.}\) Then:
    \begin{align*} F_x \amp = y + 2x \amp F_{xy} \amp = 1 \\ F_y \amp = x + \cos(y) \amp F_{yx} \amp = 1 \end{align*}
    🔗
    🔗
    So, given \(M + N \frac{dy}{dx} = 0\text{,}\) the equation is exact if
    \begin{gather*} M_y = N_x. \end{gather*}
    🔗

    Example 22.

    Consider \(2x + y^2 + 2xy y' = 0\text{.}\) Then:
    \begin{gather*} M_y = 2y = N_x \checkmark \end{gather*}
    So the differential equation is exact. Now, let \(F(x, y) = x^2 + xy^2\text{.}\) Then:
    \begin{align*} F_x \amp = 2x + y^2 = M \amp F_y \amp = 2xy = N \end{align*}
    So the solution to the differential equation is:
    \begin{gather*} x^2 + xy^2 = C. \end{gather*}
    🔗
    🔗
    How did we find \(F(x, y)\text{?}\) We can play a sort of integral-derivative ping-pong. Once we know there exists \(F\) such that \(F_x = M\text{,}\) then:
    \begin{gather*} F = \int M\ dx = \int 2x + y^2\ dx = x^2 + xy^2 + C(y) \end{gather*}
    Now, taking the partial derivative with respect to \(y\text{,}\) we should get \(N\text{:}\)
    \begin{align*} 2xy + C'(y) \amp = 2xy \quad \Rightarrow \quad C'(y) = 0 \quad \Rightarrow \quad C(y) = k. \end{align*}
    So \(F(x, y) = x^2 + 2xy + k\text{.}\) (Note: we don’t need to keep track of the \(k\text{,}\) since it can be absorbed into the \(C\) in the equation \(F(x, y) = C\text{.}\))
    🔗

    Example 23.

    Solve the initial value problem:
    \begin{align*} \frac{dy}{dx} \amp = \frac{3 - 2xy^2}{2x^2y + 4}, \quad y(1) = 1 \end{align*}
    First, put the equation in a standard form:
    \begin{gather*} \underbrace{(2xy^2 - 3)}_{M} + \underbrace{(2x^2y + 4)}_{N}\frac{dy}{dx} = 0 \\ M_y = 4xy = N_x \checkmark \end{gather*}
    So the equation is exact. Then (an alternative to the ping-pong method):
    \begin{align*} F \amp = \int 2xy^2 - 3\ dx = x^2y^2 - 3x \\ F \amp = \int 2x^2y + 4\ dy = x^2y^2 + 4y \end{align*}
    Putting these together, \(F(x, y) = x^2y^2 - 3x + 4y\text{.}\) So the implicit solution is:
    \begin{gather*} x^2y^2 - 3x + 4y = C \end{gather*}
    Applying the IC:
    \begin{gather*} 1 - 3 + 4 = C \quad \Rightarrow \quad C = 2 \\ x^2y^2 - 3x + 4y = 2 \end{gather*}
    We can find an explicit solution:
    \begin{align*} x^2y^2 - 3x + 4y \amp = 2 \\ x^2y^2 + 4y \amp = 2 + 3x \\ y^2 + \frac{4}{x^2} y \amp = \frac{2}{x^2} + \frac{3}{x} \\ \left(y + \frac{2}{x^2}\right)^2 - \frac{4}{x^4} \amp = \frac{2}{x^2} + \frac{3}{x} \\ y + \frac{2}{x^2} \amp = \pm \sqrt{\frac{2}{x^2} + \frac{3}{x} + \frac{4}{x^4}} \\ y \amp = \pm \sqrt{\frac{2}{x^2} + \frac{3}{x} + \frac{4}{x^4}} - \frac{2}{x^2} \end{align*}
    The IC decides the \(\pm\) sign:
    \begin{align*} y \amp = \sqrt{\frac{2}{x^2} + \frac{3}{x} + \frac{4}{x^4}} - \frac{2}{x^2} \end{align*}
