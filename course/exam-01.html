    2.

    Find the equilibrium solutions of the differential equation \(y' = y^3 - 2y^2 + y\text{,}\) and classify them as stable, unstable, or semistable.
    🔗
    Solution.
    Factor: \(y' = y(y^2 - 2y + 1) = y(y - 1)^2 = f(y)\text{.}\) The equlibrium solutions are \(y = 0\) and \(y = 1\text{.}\)
    🔗
    \(f(y)\) is negative on \((-\infty, 0)\) and positive on \((0, 1)\) and \((1, \infty)\text{,}\) so \(y = 0\) is an unstable equilibrium and \(y = 1\) is a semistable equilibrium.
    🔗

    3.

    Find general solutions for each of the following differential equations. (Implicit solutions are okay.)
    🔗

    (a)

    \(\displaystyle{xe^{y^2} \frac{dy}{dx} = \frac{(x+1)^2}{y}}\)
    🔗
    Solution.
    By separating variables:
    \begin{align*} \int ye^{y^2}\ dy \amp = \int \frac{(x+1)^2}{x}\ dx \\ \frac{e^{y^2}}{2} \amp = \int \frac{x^2 + 2x + 1}{x}\ dx = \int x + 2 + \frac{1}{x}\ dx \\ \frac{e^{y^2}}{2} \amp = \frac{x^2}{2} + 2x + \ln|x| + C \end{align*}
    🔗
    🔗
    🔗

    (b)

    \(\displaystyle{\left(2y^2 + 3x\right) + \left(2xy\right) \frac{dy}{dx} = 0}\)
    🔗
    Solution.
    Let \(M = 2y^2 + 3x, N = 2xy\text{.}\) Then \(M_y = 4y \neq 2y = N_x\text{,}\) so the equation isn’t exact.
    \begin{align*} \frac{M_y - N_x}{N} \amp = \frac{4y - 2y}{2xy} = \frac{1}{x} \quad \Rightarrow \quad \frac{d\mu}{dx} = \frac{1}{x}\cdot \mu \\ \int \frac{d\mu}{\mu} \amp = \int \frac{dx}{x} \quad \Rightarrow \quad \ln|\mu| = \ln|x| \quad \Rightarrow \quad \mu = x \\ \left(2xy^2 + 3x^2\right) \amp + \left(2x^2y\right) \frac{dy}{dx} = 0 \end{align*}
    Let \(A = 2xy^2 + 3x^2, B = 2x^2y\text{.}\) Then \(A_y = 4xy = B_x\text{,}\) so this equation is exact.
    \begin{align*} F(x, y) \amp = \int 2xy^2 + 3x^2\ dx = x^2y^2 + x^3 + g(y) \\ F_y \amp = 2x^2y + g'(y) = 2x^2y \\ \Rightarrow \quad g'(y) \amp = 0 \quad \Rightarrow \quad g(y) = k \end{align*}
    So the solution is:
    \begin{gather*} x^2y^2 + x^3 = C. \end{gather*}
    🔗
    🔗
    🔗

    (c)

    \(\displaystyle{xy' + y = e^x}\)
    🔗
    Solution.
    In standard form: \(\displaystyle{y' + \frac{1}{x} y = \frac{e^x}{x}}\text{.}\) Then:
    \begin{align*} r(x) \amp = e^{\int \frac{1}{x}\ dx} = e^{\ln(x)} = x \\ \int (xy)'\ dx \amp = \int e^x\ dx \\ xy \amp = e^x + C \end{align*}
    🔗
    🔗

    4.

    Find general solutions for each of the following differential equations.
    🔗

    (a)

    \(\displaystyle{y'' + 6y' + 5y = 0}\)
    🔗
    Solution.
    \(r^2 + 6r + 5 = (r + 1)(r + 5) = 0\text{,}\) so \(r = -1, -5\text{,}\) so the general solution is:
    \begin{gather*} y = C_1 e^{-x} + C_2 e^{-5x}. \end{gather*}
    🔗
    🔗
    🔗

    (b)

    \(\displaystyle{y'' - 2y' + 5y = 0}\)
    🔗
    Solution.
    \(r^2 - 2r + 5 = 0\text{,}\) so
    \begin{gather*} r = \frac{2 \pm \sqrt{4 - 20}}{2} = \frac{2 \pm 4i}{2} = 1 \pm 2i \end{gather*}
    So the general solution is:
    \begin{gather*} y = C_1 e^{x}\cos(2x) + C_2 e^{x}\sin(2x). \end{gather*}
    🔗
    🔗
    🔗

    (c)

    \(\displaystyle{y'' - 4y' + 4y = 0}\)
    🔗
    Solution.
    \(r^2 - 4r + 4 = (r - 2)^2 = 0\text{,}\) so \(r = 2\) is a repeated root. Then, the general solution is:
    \begin{gather*} y = C_1 e^{2x} + C_2 xe^{2x}. \end{gather*}
    🔗
    🔗
    🔗

    (d)

    \(\displaystyle{y'' + 6y' + 5y = 8e^{-x}}\)
    🔗
    Solution.
    The solution to the associated homogeneous equation is \(y_c = C_1 e^{-x} + C_2 e^{-5x}\text{.}\) So a guess for a particular solution would be:
    \begin{align*} y_p \amp = Axe^{-x} \\ y_p' \amp = Ae^{-x} - Axe^{-x} = (A - Ax)e^{-x} \\ y_p'' \amp = -Ae^{-x} - (A - Ax)e^{-x} = (-2A + Ax)e^{-x} \\ 8e^{-x} \amp = (-2A + Ax)e^{-x} + 6(A - Ax)e^{-x} + 5Axe^{-x} \\ 8 \amp = (-2A + Ax) + 6(A - Ax) + 5Ax \\ 8 \amp = 4A \quad \Rightarrow \quad A = 2 \end{align*}
    So the general solution is:
    \begin{gather*} y = C_1 e^{-x} + C_2 e^{-5x} + 2xe^{-x} \end{gather*}
    🔗
    🔗
    🔗

    5.

    A tank initially contains 100 L of brine with a salt concentration of 3 g/L. A 2 g/L brine solution flows into the tank at a rate of 5 L/min, and the mixture in the tank flows out through a drain pipe at the same rate. Let \(Q(t)\) be the quantity (g) of salt in the tank at time \(t\) (min).
    🔗

    (a)

    Write a formula for the volume of brine in the tank at time \(t\text{.}\)
    🔗
    Solution.
    Since the flow rates in and out of the tank are equal, the volume is constant at 100 L.
    🔗
    🔗
    🔗

    (b)

    What is the quantity \(Q(0)\) of salt in the tank at time \(t = 0\text{?}\)
    🔗
    Solution.
    \((100 \text{L})(3 \text{g/L}) = 300 \text{g}\)
    🔗
    🔗
    🔗

    (c)

    Write a differential equation involving \(Q(t)\) and \(Q'(t)\text{,}\) then solve your differential equation.
    🔗
    Solution.
    \begin{align*} \frac{dQ}{dt} \amp = (2)(5) - \left(\frac{Q}{100}\right)(5) = 10 - \frac{Q}{20} \\ Q' + \frac{1}{20} Q \amp = 10 \\ r(t) \amp = e^{\int \frac{1}{20}\ dt} = e^{t/20} \\ \int \left(Q e^{t/20}\right)'\ dt \amp = \int 10e^{t/20}\ dt \\ Q e^{t/20} \amp = 200e^{t/20} + C \\ Q \amp = 200 + Ce^{-t/20} \end{align*}
    With \(Q(0) = 300\text{:}\)
    \begin{gather*} 300 = 200 + C \quad \Rightarrow \quad C = 100 \end{gather*}
    So the solution is:
    \begin{align*} Q \amp = 200 + 100e^{-t/20} \end{align*}
