    Subsection The Constant Coefficient Case

    Consider a constant coefficient second order homogeneous linear differential equation:
    \begin{gather} a y'' + by' + cy = 0 \tag{✶} \end{gather}
    A common idea in solving certain differential equations is: guess-and-check works well for good guessers.
    🔗

    Example 30.

    Does (✶) have a solution of the form \(y = e^{rx}\) for some \(r\text{?}\) If so, then:
    \begin{align*} y' \amp = re^{rx} \\ y'' \amp = r^2e^{rx} \\ ar^2 e^{rx} + bre^{rx} + ce^{rx} \amp = 0 \\ ar^2 + br + c \amp = 0 \end{align*}
    Using the quadratic equation:
    \begin{align*} r \amp = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a} \end{align*}
    We’ll refer to \(ar^2 + br + c\) as the characteristic polynomial of (✶).
    🔗
    🔗

    Example 31.

    Consider the equation:
    \begin{gather*} y'' - 3y' + 2y = 0. \end{gather*}
    Then the characteristic polynomial is \(r^2 - 3r + 2 = (r - 1)(r - 2)\text{,}\) so both \(y_1 = e^x, y_2 = e^{2x}\) are solutions. Since these are linearly independent, the general solution must be:
    \begin{gather*} y = C_1e^x + C_2 e^{2x}. \end{gather*}
    Suppose we wanted to add initial condition information, such as \(y(0) = 1\text{.}\) Plugging this information into the general solution:
    \begin{gather*} y = C_1e^x + C_2 e^{2x} \\ 1 = C_1 + C_2 \end{gather*}
    This is not enough information to pin down a single solution. For a second order equation, an initial condition must include two pieces of information:
    \begin{align*} y(x_0) \amp = y_0 \amp y'(x_0) \amp = y_0' \end{align*}
    If we also suppose that \(y'(0) = -1\text{,}\) then \(y' = C_1e^X + 2C_2e^{2x}\text{,}\) so:
    \begin{align*} 1 \amp = C_1 + C_2 \\ -1 \amp = C_1 + 2C_2 \end{align*}
    Subtracting gives: \(2 = 0 - C_2\text{,}\) so \(C_2 = -2\text{.}\) Plugging back in to either equation gives \(C_1 = 3\text{,}\) so the unique solution satisfying the initial condition is:
    \begin{gather*} y = 3e^x - 2e^{2x}. \end{gather*}
    🔗
    🔗

    Example 32.

    Consider \(y'' + 2y' + y = 0\text{,}\) with characteristic polynomial \(r^2 + 2r + 1 = (r+1)^2\text{.}\) This has \(-1\) as a repeated root, so we have a solution \(y_1 = e^{-x}\text{,}\) but no second solution.
    🔗
    Suppose we guess \(y_2 = xe^{-x}\text{.}\) We can easily check that this is a solution:
    \begin{align*} y_2' \amp = e^{-x} - xe^{-x} = (1-x)e^{-x} \\ y_2'' \amp = -e^{-x} - (1-x)e^{-x} = (x - 2)e^{-x} \end{align*}
    Plugging in to the differential equation:
    \begin{align*} (x-2)e^{-x} + 2(1-x)e^{-x} + xe^{-x} \amp = 0 \checkmark \end{align*}
    Since \(y_1, y_2\) are linearly independent, we have the general solution:
    \begin{gather*} y = C_1e^{-x} + C_2xe^{-x}. \end{gather*}
    🔗
    🔗
    A quadratic polynomial must have either two real roots, one real repeated root, or a pair of complex conjugate roots. It remains to consider the last case.
    🔗

    Definition 33.

    The numbers \(a + bi\) and \(a - bi\) are called conjugate.
    🔗
    🔗

    Fact 34. Euler’s Formula.

    \begin{gather*} e^{i\theta} = \cos(\theta) + i \sin(\theta). \end{gather*}
    A slight variation, by plugging in \(-\theta\) and using the even/odd properties of \(\cos/\sin\text{:}\)
    \begin{gather*} e^{-i\theta} = \cos(\theta) - i \sin(\theta). \end{gather*}
    🔗
    🔗

    Example 35.

    Consider the equation \(y'' - 4y' + 5y = 0\text{,}\) with characteristic polynomial \(r^2 - 4r + 5\text{.}\) Using the quadratic equation:
    \begin{gather*} r = \frac{4 \pm \sqrt{16 - 20}}{2} = \frac{4 \pm \sqrt{-4}}{2} = 2 \pm i. \end{gather*}
    So we find two solutions \(y_1 = e^{(2 + i)x}, y_2 = e^{(2 - i)x}\) which are complex-valued functions. Using Euler’s Formula:
    \begin{align*} y_1 \amp = e^{(2 + i)x} = e^{2x} \cos(x) + i e^{2x} \sin(x) \\ y_2 \amp = e^{(2 - i)x} = e^{2x} \cos(x) - i e^{2x} \sin(x) \end{align*}
    Now, we can define new functions:
    \begin{align*} y_3 \amp = \frac{y_1 + y_2}{2} = e^{2x} \cos(x) \\ y_4 \amp = \frac{y_1 - y_2}{2i} = e^{2x} \sin(x) \end{align*}
    By the Superposition Theorem, these are also solutions to the differential equation. Since they are linearly independent (not constant multiples of each other), then the general solution to the equation is:
    \begin{gather*} y = C_1 e^{2x} \cos(x) + C_2 e^{2x}\sin(x). \end{gather*}
    🔗
    🔗
    To summarize: given \(a y'' + by' + cy = 0\text{,}\) we have three cases.
    1. With distinct real roots \(r_1, r_2\text{,}\) the general solution will be:
      \begin{gather*} y = C_1 e^{r_1x} + C_2 e^{r_2x}. \end{gather*}
      🔗
      🔗
    2. With a repeated real root \(r\text{,}\) the general solution will be:
      \begin{gather*} y = C_1 e^{rx} + C_2 xe^{rx}. \end{gather*}
      🔗
      🔗
    3. With complex conjugate roots \(\alpha \pm i \beta\text{,}\) the general solution will be:
      \begin{gather*} y = C_1 e^{\alpha x}\cos(\beta x) + C_2 e^{\alpha x} \sin(\beta x). \end{gather*}
      🔗
      🔗
