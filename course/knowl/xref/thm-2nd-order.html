Theorem 54. Second Order E+U.

Suppose \(y'' + p(x) y' + q(x) y = f(x)\text{,}\) with \(p, q, f\) continuous on an interval \(I\) which contains a point \(x_0\text{.}\) Then the initial value problem with initial condition \(y(x_0) = y_0, y'(x_0) = y_0'\) has a unique solution which is valid on \(I\text{.}\)
