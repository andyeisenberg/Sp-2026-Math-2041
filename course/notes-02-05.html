    Subsection Nonhomogeneous Equations

    Consider the nonhomogeneous equation
    \begin{align} y'' + p(t) y' + q(t) y \amp = g(t) \tag{2.1} \end{align}
    where \(g(t)\) is not identically 0. Then the associated homogeneous equation (AHE) is:
    \begin{align} y'' + p(t) y' + q(t) y \amp = 0 \tag{2.2} \end{align}
    🔗

    Theorem 38.

    Let \(y_c\) be the general solution to (2.2) and let \(y_p\) be a particular solution to (2.1). Then, the general solution to (2.1) is:
    \begin{gather*} y = y_c + y_p. \end{gather*}
    🔗
    🔗

    Example 39.

    Consider:
    \begin{align} y'' + 5y' + 6y \amp = 6t - 1 \tag{2.3}\\ y'' + 5y' + 6y \amp = 0 \tag{2.4} \end{align}
    To find the general solution to (2.4):
    \begin{align*} r^2 + 5r + 6 \amp = 0 \\ (r+2)(r+3) \amp = 0 \\ r \amp = -2, -3 \\ y_c \amp = C_1e^{-2t} + C_2e^{-3t} \end{align*}
    Let \(y_p = t - 1\text{.}\) Then:
    \begin{align*} y_p' \amp = 1 \\ y_p'' \amp = 0 \\ 0 + 5(1) + 6(t - 1) \amp = 5 + 6t - 6 \\ \amp = 6t - 1, \end{align*}
    so \(y_p\) is a solution to (2.3). Therefore the general solution to (2.3) is:
    \begin{gather*} y = y_c + y_p = C_1e^{-2t} + C_2e^{-3t} + t - 1. \end{gather*}
    🔗
    🔗
    It remains to see how to find candidate solutions \(y_p\text{.}\) To start, we’ll use the Method of Undetermined Coefficients.
    🔗

    Example 40.

    Still referring to (2.3), since the right hand side is a polynomial of degree 1, we might suspect that a solution is also a polynomial of degree 1. We write the most general such polynomial, leaving some coefficients undtermined. Then, try to determine the coefficients by plugging into the differential equation:
    \begin{align*} y_p \amp = At + B \\ y_p' \amp = A \\ y_p'' \amp = 0 \\ 0 + 5(A) + 6(At + B) \amp = 6t - 1 \\ 6At + (5A + 6B) \amp = 6t - 1 \end{align*}
    Therefore \(6A = 6\text{,}\) hence \(A = 1\text{,}\) and \(5A + 6B = -1\text{.}\) Plugging in \(A = 1\text{,}\) \(5 + 6B = -1\text{,}\) so \(B = -1\text{.}\) Therefore:
    \begin{gather*} y_p = t - 1. \end{gather*}
    🔗
    🔗
    This method will work reliably for certain types of functions that appear on the right hand side of the nonhomogeneous equation:
    🔗

    Example 42.

    Consider:
    \begin{align} y'' - 4y \amp = 2e^{2x} \tag{2.5}\\ y'' - 4y \amp = 0 \tag{2.6} \end{align}
    We first solve the AHE:
    \begin{align*} r^2 - 4 \amp = 0 \\ (r - 2)(r + 2) \amp = 0 \\ r \amp = 2, -2 \\ y_c \amp = C_1e^{-2x} + C_2e^{2x} \end{align*}
    The right hand side of (2.5) is an exponential, so we might make the guess:
    \begin{gather*} y_p = Ae^{2x}. \end{gather*}
    However, we can immediately see this guess won’t be a solution of (2.5), since it’s already a solution of (2.6)! So we adjust our guess by multiplying by \(x\text{:}\)
    \begin{align*} y_p \amp = Axe^{2x} \\ y_p' \amp = Ae^{2x} + 2Axe^{2x} = (A + 2Ax)e^{2x} \\ y_p'' \amp = 2Ae^{2x} + 2(A + 2Ax)e^{2x} = (4A + 4Ax)e^{2x} \end{align*}
    Plugging these formulas into the original differential equation:
    \begin{align*} (4A + 4Ax)e^{2x} - 4Axe^{2x} \amp = 2e^{2x} \\ 4Ae^{2x} \amp = 2e^{2x} \\ 4A \amp = 2 \\ A \amp = \frac{1}{2} \\ y_p \amp = \frac{xe^{2x}}{2} \end{align*}
    Now, the general solution to (2.5) is:
    \begin{gather*} y = C_1e^{-2x} + C_2e^{2x} + \frac{xe^{2x}}{2} \end{gather*}
    🔗
    🔗

    Example 43.

    Consider:
    \begin{align} y'' + 2y' + y \amp = e^{-x} \tag{2.7}\\ y'' + 2y' + y \amp = 0 \tag{2.8} \end{align}
    We first solve the AHE:
    \begin{align*} r^2 + 2y + 1 \amp = 0 \\ (r +1)^2 \amp = 0 \\ r \amp = -1 \\ y_c \amp = C_1e^{-x} + C_2xe^{-x} \end{align*}
    The right hand side of (2.7) is an exponential, so we might make the guess:
    \begin{gather*} y_p = Ae^{-x} \end{gather*}
    However, this is already part of \(y_c\text{,}\) so we adjust:
    \begin{gather*} y_p = Axe^{-x} \end{gather*}
    However, this is still part of \(y_c\text{,}\) so we adjust again:
    \begin{align*} y_p \amp = Ax^2e^{-x} \\ y_p' \amp = 2Axe^{-x} - Ax^2e^{-x} = (2Ax - Ax^2)e^{-x} \\ y_p'' \amp = (2A - 2Ax)e^{-x} - (2Ax - Ax^2)e^{-x} = (2A - 4Ax + Ax^2)e^{-x} \end{align*}
    Then:
    \begin{align*} (2A - 4Ax + Ax^2)e^{-x} + 2(2Ax - Ax^2)e^{-x} + Ax^2e^{-x} \amp = e^{-x} \\ 2Ae^{-x} \amp = e^{-x} \\ 2A \amp = 1 \\ A \amp = \frac{1}{2} \end{align*}
    So the general solution to (2.5) is:
    \begin{gather*} y = C_1e^{-x} + C_2xe^{-x} + \frac{x^2e^{-x}}{2}. \end{gather*}
