    Subsection Integrating Factor

    Given \(M(x, y) + N(x, y) \frac{dy}{dx} = 0\) with \(M_y \neq N_x\) (so the equation is not exact), can we find some \(\mu(x, y)\) to multiply by to get an exact equation? That is, we want \(\mu(x, y)\) such that:
    \begin{gather*} \mu M + \mu N \frac{dy}{dx} = 0 \end{gather*}
    is exact, which requires \((\mu M)_y = (\mu N)_x\text{.}\) Hence:
    \begin{gather*} \mu_y M + \mu M_y = \mu_X N + \mu N_x, \end{gather*}
    which is a partial differential equation, beyond the scope of this course.
    🔗
    What if we assume \(\mu = \mu(x)\) is a function of only one variable? Then:
    \begin{align*} (\mu M)_y \amp = (\mu N)_x \\ \mu M_y \amp = \frac{d\mu}{dx} N + \mu N_x \\ \frac{d\mu}{dx} N \amp = \mu M_y - \mu N_x \\ \frac{d\mu}{dx} \amp = \frac{M_y - N_x}{N} \mu \end{align*}
    If \(\frac{M_y - N_x}{N}\) is an expression in terms of only \(x\text{,}\) then this is a first order differential equation in terms of \(\mu\text{.}\)
    🔗
    Similarly, if \(\mu = \mu(y)\text{,}\) then:
    \begin{gather*} \frac{d\mu}{dy} = \frac{N_x - M_y}{M} \mu \end{gather*}
    will be a first order differential equation in terms of \(\mu\) if \(\frac{N_x - M_y}{M}\) only involves \(y\text{.}\)
    🔗

    Example 24.

    Consider the equation:
    \begin{gather*} \underbrace{(2y^2 + 3x)}_{M} + \underbrace{(2xy)}_{N} \frac{dy}{dx} = 0. \end{gather*}
    Then \(M_y = 4y \neq 2y = N_x\text{,}\) so the equation is not exact. Then:
    \begin{gather*} \frac{M_y - N_x}{N} = \frac{4y - 2y}{2xy} = \frac{2y}{2xy} = \frac{1}{x}, \end{gather*}
    which only involves \(x\text{.}\) So we can set up and solve the differential equation:
    \begin{align*} \frac{d\mu}{dx} = \frac{1}{x} \mu \\ \int \frac{d\mu}{\mu} = \int \frac{dx}{x} \mu \\ \ln|mu| \amp = \ln|x| + C \\ |mu| \amp = e^{\ln|x| + C} \\ \mu \amp = x. \end{align*}
    Multiplying the original equation, we get:
    \begin{gather*} \underbrace{(2xy^2 + 3x^2)}_{A} + \underbrace{(2x^2y)}_{B} \frac{dy}{dx} = 0 \\ A_y = 4xy = B_x \checkmark \end{gather*}
    So this equation is exact.
    \begin{align*} F(x, y) \amp = \int A\ dx = x^2y^2 + x^3 + C(y) \\ \xrightarrow{\partial/\partial y} \quad 2x^2y + 0 + C'(y) \amp = 2x^2y \quad \Rightarrow \quad C(y) = k \end{align*}
    So the implicit solution to the equation is:
    \begin{gather*} x^2y^2 + x^3 = C. \end{gather*}
    🔗

    Subsection Second Order Linear ODEs

    Definition 25.

    A second order linear ODE can be put in the form:
    \begin{gather*} y'' + p(x) y' + q(x)y = f(x). \end{gather*}
    If \(f(x) \equiv 0\text{,}\) the equation is called homogeneous.
    🔗
    🔗

    Theorem 26. Superposition.

    If \(y_1, y_2\) are solutions to a homogeneous equation, then so are:
    \begin{gather*} y = C_1 y_1 + C_2 y_2 \end{gather*}
    for any constants \(C_1, C_2.\)
    🔗
    🔗

    Definition 27.

    Functions \(y_1, y_2, \dotsc, y_n\) are linearly independent if the only way to have:
    \begin{gather*} a_1y_1 + a_2y_2 + \dotsb + a_ny_n = 0 \end{gather*}
    is \(a_1 = a_2 = \dotsb = a_n = 0.\)
    🔗
    🔗
    For \(n = 2\text{,}\) \(y_1, y_2\) are linearly independent if and only if they are not constant multiples of each other.
    🔗

    Theorem 28.

    If \(y_1, y_2\) are linearly independent solutions to a second order homogeneous equation, then the general solution is:
    \begin{gather*} y = C_1y_1 + C_2y_2. \end{gather*}
    🔗
    🔗
    Note that this is a different conclusion from the superposition theorem, which says "these functions are also solutions" but doesn’t guarantee that it’s a complete list of all solutions.
    🔗

    Example 29.

    Consider \(y'' - 3y' + 2y = 0.\) Let \(y_1 = e^x, y_2 = e^{2x}\text{.}\) Then:
    \begin{align*} y_1' \amp = e^x \amp y_2' \amp = 2e^{2x} \\ y_1'' \amp = e^x \amp y_2'' \amp = 4e^{2x} \end{align*}
    We can easily check:
    \begin{align*} e^x - 3e^x + 2e^x \amp = 0 \checkmark \\ 4e^{2x} - 3(2e^{2x}) + 2e^{2x} \amp = 0 \checkmark \end{align*}
    So \(y_1, y_2\) are solutions to the equation. They are also linearly independent, since they’re not multiples of each other. Therefore the general solution to the equation is:
    \begin{gather*} y = C_1e^x + C_2e^{2x}. \end{gather*}
